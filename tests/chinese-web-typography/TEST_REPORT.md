# 测试报告

2026-09-11，在 macOS 上使用 Playwright 1.62.1 / headless Chromium 151.0.7922.34 实测。

## 案例与过程

六类真实业务形态的模拟案例：叙事与公告标题、正文混排、商品卡片、订单表格、表单与长按钮、配送说明。内容包含长短标题、长 URL 与订单号、大金额、缺失值、繁体、非 BMP 汉字和 emoji。

“回信里，还有一个数字。”及其引文来自用户提供的截图。`before.html` 是构造的故障对照，不是原网站源码；其他内容是虚构业务数据。

独立代理使用技能修复原始页面，主代理另行运行浏览器测试并实际查看代表性截图。第一轮发现标题 `balance` 仍断成“回信里，还有 / 一个数字。”，以及 320px 根字号放大后正文长英文撑宽页面。这两个实际发现已用于补充技能并修复样例。

## 结果

| 配置 | 结果 |
| --- | --- |
| 320 / 390 / 768 / 1440px 常规内容 | 4 组通过 |
| 320 / 768px 根字号 200% | 2 组通过 |
| 390px 系统衬线字体替换 | 1 组通过 |
| 320px 动态长内容 | 1 组通过 |
| 320px 动态短内容 | 1 组通过 |

最终 9 组配置、86 项适用断言通过。检查包括整页横向溢出、被测文字裁切、语言属性、指定标点样例、URL/订单号保真、缺失金额、运行时错误、键盘访问与适用的标题断行回归。键盘覆盖表格聚焦、需要时的局部滚动、Tab 到地址框和提交按钮以及 Enter 操作。

故障对照在 320px 下被撑到 1162px，且检测到商品名、错误提示、说明文本裁切；1440px 也检测到裁切。因此 baseline 显示失败项是预期结果，命令本身不因这些预期失败返回非零。

主代理查看过修改前窄屏全页，以及修改后窄屏标题、表单、放大正文、桌面标题与卡片、衬线正文截图；未见所查看样例明显缺字或裁切。结构校验另行通过，不等于行为正确性证明。

## 局限

本次不是生产站点测试或大规模模型评测。未测 Safari、Firefox、真实手机、屏幕阅读器或完整 WCAG 合规。根字号 200% 不等于真实浏览器缩放；系统字体替换不等于网络字体加载/失败测试。字体与操作系统差异可能改变换行结果。弹窗、导航、代码块有技能指导，但未包含在这次 fixture 中。

W3C/MDN 链接作为参考列入技能，本次未能联网重新核对文档和最新兼容性。使用新 CSS 特性时应进一步查验目标浏览器。
