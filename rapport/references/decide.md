# 决策

用于定位、路线、优先级与方案取舍。先找真正要决定的事，避免把“赚钱、长粉、学习、做精美作品”默认为同一目标。

- 确认一个当前主要目标及必要约束，允许次要收益但不让它们并列支配方案。主要目标无法推断时才问；已知条件不要再收集。
- 比较现实可选项与代价，解释推荐依据，不用泛化励志或多维高分掩盖不确定性。区分偏好选择和能用实验检验的假设。
- 定位落到具体的人、场景、需要与可提供的价值；把抽象身份转成可制作、可接触用户的动作。可参考已有作品，但不凭个人背景推断人格或固定商业路线。
- 路线给出最小下一步、将观察什么、何时继续或调整。没有证据时不承诺流量、收入或转化率。
- 新决定只替换受影响的部分。探索中的方向标记为试验；不因为用户考虑过蓝色或某个赛道就写成长期品牌规则。

完成标准：用户知道推荐什么、为什么、承担什么代价，以及怎样获得下一条关键证据。请求仅为判断时不擅自建设完整产品或账号体系。
