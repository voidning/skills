# 文字规则

## 断行：先区分布局约束与语言规则

浏览器的中文默认换行可以发生在许多汉字之间；标点禁则与词组语义是不同层面的事。标题不自然时，检查 `<br>`、块级 span、`max-width`（尤其沿用英文标题的 `ch`）、`nowrap`、flex/grid 最小宽度和祖先布局。

- `ch` 以字体的“0”字形度量，不能当作中文字符数。`em`/`ic` 也只是布局度量，不保证每行恰有固定字数。
- `word-break: normal` 通常适合中文自然换行。`keep-all` 会限制 CJK 字间断行，可能让整段溢出；`break-all` 会破坏英文词和标识符的阅读。
- `overflow-wrap: anywhere` 可针对不可控长网址/标识符提供应急折行，也能降低相关最小内容宽度。它不是语义断行工具；不要无差别用于金额和正常标题。
- 长词也可能藏在普通正文中，而不只在 URL 专用组件里。对允许任意业务文案的正文容器，可局部设置 `overflow-wrap: break-word` 作为单词确实放不下时的兜底，保留 `word-break: normal`；若问题涉及 flex/grid 最小内容宽度，再结合 `min-inline-size: 0` 或 `anywhere` 判断。用窄屏和放大文字验证，不从普通字号不溢出推导出放大也安全。
- `line-break: strict` 可作为中文内容的候选策略，结合地区、浏览器和实际标点检查；不能承诺修复所有行首行尾问题。普通标点的禁则不是必须设置 strict 才存在。
- `text-wrap: balance` 适合有限行数的短标题；不同浏览器的算法、行数限制可能不同。`pretty` 是浏览器相关的排版增强。两者都应有自然换行回退，不用它们保证中文词组不拆开。
- `<wbr>` 适合明确可断开的超长标识符等场景，不逐字插入。给少量短语加 `nowrap` 前，确认最窄容器和放大文字下仍放得下；放不下就允许恢复自然断行。

例如“回信里，还有一个数字。”可以在空间充足时完整显示，需要设计分行时考虑“回信里，/还有一个数字。”；这不是每个屏幕必须保持两行的模板。动态标题不要靠手写每个分行来维持布局。

已确认语义不自然的固定短标题，可用少量内联分组，组间允许换行，组内在极窄空间仍能退回自然换行。例如对“回信里，”和“还有一个数字。”分别使用 `display: inline-block; max-inline-size: 100%; white-space: normal`，并检查组内的 `text-wrap` 与行高。这是局部候选实现，不是全站逐句分组要求；长短动态替换仍须工作。不能看到已设置 `balance` 就跳过实际标题行序检查。

## 标点与混排

- 中文句子通常使用中文标点；英文片段、代码、产品正式名称遵循其自身写法。简体常见弯引号与繁体常见直角引号按地区/项目处理，引用原文不擅改。
- 检查句号、逗号、顿号、右括号/右引号等是否不自然地单独出现在行首，左括号/左引号是否被留在行尾；不要手动在每个标点两侧插入不可见字符修复。
- 破折号、省略号、连续标点要看实际字体与换行表现。标点压缩、悬挂等高级排版只在项目需要且目标浏览器可验证时使用。
- 中英文视觉间距保持一致。编辑自有文案时可按项目规范留空格；不要以正则批量修改任意文本节点，更不要污染链接、邮箱、代码、文件名或标识符。
- 不用 `letter-spacing` 模拟中英间距；避免正文过大的字距和以空格排版对齐。`text-autospace` 等新特性须检查目标浏览器支持及回退，不能作为唯一方案。

## 字体与可读性

- 沿用项目字体栈，确保存在适当中文回退。简繁地区字形与语言标签保持一致；自定义子集字体需要考虑生僻字、繁体、数字和标点的回退。
- 检查真实中文字体的字重与行盒，警惕假粗体、过细字重、拉丁字体与中文回退在字号/基线上的落差。不要通过大面积位移逐字修补基线。
- 在字体加载前后检查标题行数、按钮高度和卡片稳定性；没有网络字体时，不制造无必要的下载依赖。
- 正文可从约 1.6–1.85 的无单位行高开始试排，短标题可更紧凑；这是试排范围，不是通用规范。字号优先沿用可读的项目比例，避免缩字号掩盖空间不足。
- 中文长正文不要照搬英文极宽行长或默认居中。按实际阅读密度选择行宽；移动端用可用空间，不固定字数。
- 缺字必须结合实际字形查看；`document.fonts.check()` 成功不能证明每个字都存在，也不能证明选中了期望字体。

## 数字、单位与不可拆内容

- 地区化日期、时间、货币、千分位与小数位可使用 `Intl` 或项目已有格式化工具；显示精度不应改变原始值。缺失值不能默认为 0。
- 金额、百分比、短数值与单位可在局部保持整体，但先测试最大金额/最长单位；必要时增加列宽或局部滚动，不能让它们撑坏页面。
- 长订单号、地址、链接与名称通常应允许折行或提供完整查看；不要把整个长字段视为一个不可拆短语。
- 对齐数字列可用右对齐与 `font-variant-numeric: tabular-nums`；等宽数字取决于字体支持，不能代替验证。
