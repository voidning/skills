# 视觉规范与可变部分

## 固定的系列识别

| 项目 | 默认值 |
| --- | --- |
| 背景 | 暖白 `#F7F5EF` |
| 主文字 | 深灰 `#302F2B` |
| 次文字 | `#75736C` |
| 强调 | 陶土橙 `#C66B4E` |
| 选中底色 | 浅橙 `#EEDDD2` |
| 窗口底色 | `#FCFBF7` |
| 边线 | `#B6B2A9`，1080 宽时约 2–3 px |
| 中文 | 清晰黑体；标题中粗，正文常规 |
| 英文、数字 | 等宽字体 |
| 图文／封面 | 默认 1080×1440，3:4 |
| 视频 | 默认 1080×1920，9:16，30 fps |
| 音频 | 默认无配音、无 BGM；轻量打字、切换和动作音 |

暖白留白、大字号主题、细线窗口、橙色强调是核心。不要加入品牌星芒，不把视觉风格等同于模拟某产品完整界面。

## 排版

- 视频关键内容优先放在 x≈84–934、y≈234–1550 范围，给顶部、底部和右侧平台控件留余地。安全区只是本系列设计起点，不是平台保证；实际发布界面如有差异再检查。
- 1080 宽画面：主标题约 70–106 px，正文约 36–50 px，辅助字约 26–32 px。图文封面主题可达 110–130 px。以实际中文长度与手机阅读验证调整。
- 标题不要塞满一行；窗口、连线、概率和文字对齐。辅助说明不能成为承载关键事实的唯一位置。
- 动画示意标注应靠近示例，并在缩略图上可辨认。不要仅放在将被平台遮住的最底部。

## 动态语法

- 打字：逐字视觉演示，保留光标；讲技术机制时不要把汉字数量与 token 数量混为一谈。
- 概率：同时展开各条目；只有真实归一化概率才暗示和为 100%。示意数值必须标明，不凭动画快慢制造性能实测感。
- 流程：节点高亮 → 数据沿连线移动 → 状态更新。分支与返回路径可用同一套窗口和连线表达。
- 轻转场：短淡化、细微位移；避免每屏飞入、强闪烁和大面积无意义运动。
- 音效与发生的动作对齐，不给静态画面铺连续音床。

## 可变部分

每期可改变案例、节点数量、窗口布局、卡片数量、节奏、总时长和动效类型。参考视频的 47 秒、北京美食、三项概率、小游戏、四章页脚都不是系列硬性模板。先用内容决定结构，再套视觉规范。
